# PSA Bed 조립·충전 모션그래픽

`index.html`을 브라우저로 바로 열면 재생된다. 외부 라이브러리·서버·인터넷이 필요 없다(Canvas 2D 단일 파일).

## 구성 (약 52초, 12장면 · 평면 2D 스타일)

| 구간 | 장면 |
|---|---|
| 제작 0–10 s | 설계 도면 → 착착 조립(쉘·하부 경판·상부 경판·노즐·TE 포트·지지 다리가 도면 자리로 날아와 끼워짐) → 명판·수압시험 |
| 충전 10–39 s | 단면 전환 → 호퍼 설치 → 층마다 톤백이 내려와 호퍼로 붓고, 호퍼가 노즐로 빠지며 구슬이 탑 안으로 떨어져 쌓임: 세라믹 볼 → 메시 스크린 → 활성 알루미나 → 활성탄 → 제올라이트 5A → 스크린 + 세라믹 볼 |
| 운전 39–52 s | 원료·제품 배관 연결 → 하부→상부 가스 흐름, 성분별 흡착 위치 표시 |

구슬 하나하나가 톤백 → 호퍼 더미 → 노즐 → 자유낙하 → 더미에 부딪혀 굴러 제자리까지 이어지는 궤적을 가진다. 호퍼 안 더미는 아래 구슬이 빠지는 만큼 전체가 내려오며 입구 쪽으로 모인다.

## 조작

- 재생/일시정지(Space), 처음부터, 3초 이동(←/→), 재생 속도, 반복
- 타임라인을 끌거나 오른쪽 장면 목록을 누르면 해당 장면으로 이동
- `index.html?t=33&pause` 처럼 주소에 시각을 주면 그 장면에서 멈춘 채 연다

## 주의

- 층 구성(알루미나/활성탄/5A)과 성분별 흡착 위치는 H₂ PSA의 일반적인 3층 충전을 예로 든 **설명용 그림**이다. 모델의 실제 층 높이·입자 크기·조성과 연결되어 있지 않다.
- 모든 장면은 시각 `t`만의 함수로 그려서 되감기·건너뛰기를 해도 같은 화면이 나온다.
