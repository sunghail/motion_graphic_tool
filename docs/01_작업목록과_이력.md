## 진행 이력

### 1. PSA 흡착탑 조립·충전 (P1 → P2)

1. **요청:** "PSA bed가 처음에 메탈로 조립되고 안에 충전제가 차서 한 bed가 구성되는 상세한 모션그래픽을, 폴더 하나 만들어서."
   - 첫 판: HTML 한 파일 + Canvas 2D (P1).
   - 장면: 설계 도면 → 조립 → 수압시험 → 단면 → 호퍼 → 층별 충전 → 배관 → 가스 흐름.
2. **요청:** "용접 같은 게 아니라 착 조립되는 느낌으로 한 단계로 줄이고, 2D 애니메이션 느낌으로. 흡착제도 깔때기에 이미지가 박힌 게 아니라 진짜 구슬이 떨어지게."
   - 부품이 날아와 **스프링으로 찌그러졌다 복원**되는 "착!" 조립으로 바꿨다.
   - 평면 2D 스타일로 바꿨다: 단색 면, 진한 외곽선, 명암 띠.
   - 구슬 1008개가 각각 궤적을 갖게 했다: 톤백 → 호퍼 더미 → 노즐 → 자유낙하 → 더미에 부딪혀 굴러 자리 잡음.
3. **요청:** "모션그래픽 관련 유명한 skill을 인터넷에서 찾아봐." → 조사 결과 Remotion Agent Skills(`remotion-dev/skills`)를 찾았다.
4. **요청:** "Remotion Agent Skills로 새 파일에 다듬어 봐. 이 스킬은 여기서 로컬로만."
   - `03_Bed_조립_Remotion`를 새로 만들었다(P2).
   - 스킬은 그 폴더의 `.claude/skills/`에만 설치했다. 전역 설치는 하지 않았다.
5. **요청:** "도면 자리에 뭐 생긴다 이런 건 말고, 전체적으로 어떤 글이 있는지 먼저 보여줘."
   - 화면 문구 전체를 표로 보여 주고 확인을 받았다. 이후 모든 작업의 관례가 되었다.
6. **요청:** "흡착제 아래부터 잡히는 거야, 중간까지 가서 잡히는 게 아니라. 조립 설명은 'PSA가 조립됩니다' 정도로 간단히. 내가 조립하는 사람은 아니니까."
   - 흡착을 **각 층의 아래(입구)부터 차오르는 띠**로 바꿨다(`ZONES`).
   - 조립 장 문구를 "PSA 흡착탑 한 기가 조립됩니다.", 점검 장 문구를 "완성된 흡착탑을 점검합니다."로 줄였다.
7. **요청:** "60프레임으로 영상 만들어." → 1920×1080·60fps로 렌더링했다(3474프레임).
8. **요청:** "'활성탄에서 가운데로부터 쌓여 옆으로 굴러갑니다'는 필요 없는 말. 제올라이트는 최종적으로 다른 가스를 통과시키지 않기 위한 것. CO, CO₂, CH₄, N₂ 등은 대부분 AC에서 걸러지고 Ze에서는 N₂만 조금, 아래쪽에."
   - 흡착 배치를 고쳤다. CO₂·CH₄·CO·N₂는 모두 활성탄 한 층 안에서 **강한 것부터 아래에서 위로 쌓이게** 했다.
   - N₂의 30%만 제올라이트 5A 바닥(`N2z`)에 붙게 했다.
   - 설명 문구를 바꿨다.
     - AC: "CO₂ · CH₄ · CO · N₂ 대부분을 잡는 주 흡착층입니다."
     - 5A: "마지막 방어층. 남은 불순물이 제품 쪽으로 새지 않게 막습니다."

### 2. CCS CO₂ 흡수 공정 (P3)

1. **요청:** "CCS하는 것도 애니메이션으로. CO₂ 흡수 공정. 모호한 건 먼저 질문하고, 글은 대략 컨펌받고."
   - 질문 4개를 먼저 했고 사용자가 답했다.
     - 범위: CCS 전체 라인에서 **압축까지만**
     - 배가스원: **LNG 복합발전**
     - 흡수제: **MEA 수용액 + 분자 장면**
     - 형식: **PSA 영상과 같은 형식 + 조립 장면 포함**
2. **요청(문구 수정):**
   - "굴뚝으로 나갑니다" → "**흡수탑 상단으로 배출합니다**"
   - "열을 받으면 결합이 풀리고" → "**열을 받아 결합이 깨지고**"
3. **요청:** "열교환기를 더 디테일하게. 배가스 냉각탑은 필요 없어. 유체 흐름 디테일을 챙겨. 재생탑·리보일러에서 물이 사각형으로, 모양에 안 맞게 들어가 있고 열교환기 파이프도 비껴 나가 있어."
   - 배가스 냉각 장을 뺐다. 이후 장의 시각을 다시 짜지 않도록 **이야기 시계를 7초에서 12초로 건너뛰게** 했다(`SKIP_AT=7`, `SKIP=5`).
   - 열교환기를 판형 박스에서 **쉘앤튜브**로 바꿨다: 튜브 5개, 배플 3장, 새들, 보닛, 튜브시트, 노즐 정렬.
   - 리보일러는 **케틀형**이다: U자 튜브 다발, 넘침판(weir), 넘침 칸.
   - 모든 액면을 용기 안쪽 모양 **clipPath**로 자르고 물결 표면을 넣었다.
   - 배관이 설비에 닿는 곳에 플랜지를 달았다.
4. **요청:** "작업 진행되고 있나" / "일단 영상 뽑아봐." → 렌더링했다(4014프레임, 67초).
5. **요청:** "분자 위에 선이 생겨서 분자가 가려진다. 흡수탑·탈거탑에서 액체가 내려가며 CO₂를 잡는 게 더 잘 보였으면. 속도도 약간 늦추고. 이 부분만 수정해서 영상."
   - 분자 장면에서 결합선을 원자보다 **먼저** 그리게 순서를 바꿨다.
   - 흡수탑 CO₂ 점 비율을 32%로 올리고, 잡히는 순간 고리 효과를 넣었다.
   - 잡힌 CO₂는 액적 레인으로 옮겨 타 내려가게 했다(`LIQ=72`, `GAS=48`).
   - 재생탑에서는 CO₂가 액적에 실려 내려오다 떨어져 오르게 했다(`RIDE=1.3`, `RISE=55`).

### 3. 2탑 PSA (P4)

1. **요청:** "2bed PSA에 관한 거 너가 자세하게 구성해서 애니메이션으로."
   - 구성은 직접 짰다: 설비 조립 → 6단계 사이클 한 바퀴 천천히 → 3배속 연속 운전.
   - 6단계: 가압/탈압 → 흡착/퍼지 → 균압 → 반대로 반복. 밸브는 V1–V7 일곱 개다.
2. **요청(작업 중 추가):** "2개 버전으로, 지금처럼 한 것과 3D로 실제처럼. 충분한 시간을 가지고 제작해."
   - 같은 `sim.ts`를 공유하는 2D(SVG)와 3D(Three.js) 두 컴포지션으로 만들었다.
3. **요청:** "조금 더 리얼리티하게." (3D에 적용)
   - 용기: 이음 용접선, 맨홀, 러그, 플랫폼·난간·케이지 사다리, H형 다리와 앵커볼트, 압력계·전송기를 넣었다.
   - 배관: 플랜지 볼트, 식별 색띠, 파이프랙·받침·침목을 넣었다.
   - 밸브: 액추에이터가 달린 볼밸브로 바꿨다.
   - 현장: 자갈·콘크리트 절차 텍스처, 하늘 그라데이션, 안개를 넣었다.
   - 배관을 불투명하게 하고, 지평선의 딱딱한 경계선도 없앴다.

## 사용자가 정한 방향 (다음 작업에도 적용)

- **글보다 그림.** 조립 과정은 "PSA가 조립됩니다" 정도로만 소개한다. 사용자는 조립하는 사람이 아니다.
- **화면 문구는 먼저 확인받는다.** 모호한 점은 만들기 전에 질문한다.
- **현실성.**
  - 흡착은 층의 **아래(입구)부터** 잡힌다.
  - PSA 층 역할: AC가 주 흡착층, 5A는 최종 방어층(N₂ 조금, 아래쪽).
  - 액체는 용기 모양에 맞게, 배관은 노즐에 정확히 맞게 그린다.
- **보이게.** 분자가 선에 가려지면 안 된다. 핵심 현상(CO₂가 잡히는 모습)은 조금 느리게, 크게 보여 준다.
- **60fps**로 뽑는다(P1~P4). P5는 예시라 30fps다(Remotion 클립은 60).
- **스킬은 로컬 설치만** 한다(프로젝트 `.claude/skills/`).
