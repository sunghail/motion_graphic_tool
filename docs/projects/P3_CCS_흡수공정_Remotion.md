# P3 CCS MEA 흡수 공정 — Remotion 영상

- 소스: [`projects/P3_ccs_remotion/`](../../projects/P3_ccs_remotion/) (원래 작업 폴더 이름: `04_CCS_흡수공정_Remotion`)
- 결과: `out/ccs-capture-60fps.mp4`
  - 61,524,452 B (58.7 MiB), 66.94 s, 4014프레임
  - H.264 High yuvj420p 1920×1080 60fps + AAC 48 kHz 스테레오
  - 30 MB를 넘어서 데스크톱 앱에서만 볼 수 있다.
- 만든 날: 2026-09-23 (결과 16:49)
- 도구: Remotion 4.0.527, React 19.1.0, TypeScript 5.8.3. 스킬은 P2 폴더에서 복사해 이 폴더에만 두었다.

## 사용자가 정한 범위

| 질문 | 답 |
|---|---|
| 범위 | CCS 전체 라인에서 **압축까지만** |
| 배가스원 | **LNG 복합발전** |
| 흡수제·표현 | **MEA 수용액 + 분자 장면** |
| 형식 | **PSA 영상(P2)과 같은 형식 + 조립 장면 포함** |

공정 흐름: 배가스 → 흡수탑(상단에 수세 구간) → 린/리치 열교환기 → 재생탑 + 케틀 리보일러 → 응축기 → 환류 드럼 → 3단 압축(단 사이 인터쿨러).
린 용액 복귀 배관에는 쿨러가 있다.

**Intro**

- 문구 수정 두 곳은 사용자가 직접 정했다.
  - "굴뚝으로 나갑니다" → "흡수탑 상단으로 배출합니다"
  - "결합이 풀리고" → "열을 받아 결합이 깨지고"
- **배가스 냉각 장 삭제**: 원래 7–12 s에 있던 장을 사용자 요청으로 뺐다.
  - `storyTime(v) = v < 7 ? v : v + 5`로 영상 7 s에서 이야기 12 s로 건너뛴다. 그래서 다른 장과 신호의 시각은 그대로 둘 수 있었다.
  - 효과음은 `videoTime(s)`로 되돌려 배치한다(sim.ts:99-102).
- **패널**
  - 범례 카드(y 580)는 7 s부터 보인다. 흐름 8종(배가스, 처리 가스, 린 용액, 리치 용액, 스팀, CO₂, 응축수, 냉각수)과 분자 4종(CO₂, N₂, O₂, H₂O)을 보여 준다.
  - 진행 막대는 10칸이고, 설비 : 포집 : 재생 : 압축 = 1 : 3 : 4 : 2다.

**Outro**
- "CO₂ 포집 완료"와 상자 4개: 배가스 → 흡수 → 재생 → 압축.

## 분자 확대 장면 (`Zoom.tsx`)

| 장면 | 이야기 시각 | 확대 위치 | 내용 |
|---|---|---|---|
| 흡수 | 19–25 s | 흡수탑 중간 [340, 470] | 기체 쪽 CO₂(O=C=O)가 액면 아래로 내려와 MEA①의 N에 붙음 → 120°로 굽고 이중결합 하나가 단일결합으로 → H⁺가 MEA②의 N으로 옮겨 감 → −, + 전하 표시 → 이름이 MEA–COO⁻ / MEAH⁺로 바뀜. 반응식 "2 MEA + CO₂ → MEA–COO⁻ + MEAH⁺" |
| 재생 | 41–46 s | 재생탑 중간 [740, 440] | 아래에서 열 물결 5줄 → 결합체가 떨림 → 결합이 끊기고 H가 돌아감 → CO₂가 위로 떠남. 반응식 "MEA–COO⁻ + MEAH⁺ → 2 MEA + CO₂" + 빨간 "열" 배지 |

- 렌즈: 중심 (720, 520), 반지름 300. 그림자, 5 px 테두리, 대상 지점까지 점선이 이어진다.
- 렌즈 안은 기체 영역(`#f5f9ff`)과 물결 액면 아래 액체 영역(`#d6ebff`)으로 나뉘고, 물 분자 14개가 흔들린다.
- 원자: O 빨강 r17, C 회색 r16, N 파랑 r17, H 흰색 r9. 분자 전체를 1.3배로 키웠다.
- **결합선을 원자보다 먼저 그린다**(Zoom.tsx:113-123). 사용자가 "분자 위에 선이 생겨 가려진다"고 지적해서 고쳤다.

## 설비 표현

**조립** (0–7 s)
- 도면 점선이 먼저 나온다.
- 흡수탑(1.0–1.45 s)과 재생탑(1.6–2.05 s)이 위에서 떨어져 "착!"과 화면 흔들림을 준다.
- 이어서 열교환기, 리보일러(오른쪽에서), 응축기, 드럼이 들어온다.
- 톡 튀어나오는 부품: 펌프 3.8/3.95/4.1 s, 쿨러 4.3 s, 압축기 4.6/4.8/5.0 s, 인터쿨러 4.7/4.9 s.
- 배관은 5.2–6.4 s에 그려지고, 라벨은 5.9–6.6 s, 내부 단면은 6.1–6.8 s에 나온다.

**흡수탑** (`ABS` cx 340, 110–730, r 62)
- 충전물은 148–200(수세)과 262–655 구간이다. 분배기는 y 240에 있다.
- 배가스 점이 y 684에서 들어와 48 u/s로 오른다. 초당 9개, 6개 레인이다.
  - 구성: CO₂ 32%, N₂ 40%, O₂ 16%, H₂O 12%. 실제 약 4%보다 CO₂를 과장했다.
- CO₂의 90%가 잡힌다. 잡히는 높이 식이 입구 쪽으로 몰리게 되어 있다(y 640 → 300).
- 잡힐 때: 주황 고리 → 0.4 s 동안 가까운 액적 레인으로 옮겨 탐 → 72 u/s로 내려감 → 바닥 액면(y 704)에서 사라짐.
- 액적은 레인마다 24 u 간격이다. 위는 린(파랑), 아래는 리치(주황)로 섞인다. 수세 구간은 냉각수색이다.

**재생탑** (`STR` cx 740, 170–700, r 55)
- CO₂는 이야기 35 s부터 초당 7개가 나온다. 액적에 실려 1.3 s 내려오다 y 296–596(아래쪽이 많음)에서 빨간 고리와 함께 떨어진다.
- 떨어진 CO₂는 55 u/s로 오르며 흩어진다.
- 리보일러 증기는 흰 원(초당 5개)으로, 옆 노즐(y 646)로 들어와 오른다.
- 환류 물 액적은 212–252 구간에 있다(37.8 s부터).

**쉘앤튜브 열교환기** (`HX` x 450–620, y 500–560, 헤드 430/640)
- 튜브 5개(y 510–550)에는 리치가 왼쪽에서 오른쪽으로 흐르며 점점 뜨거운 색이 된다.
- 셸 쪽은 배플 3장(x 497 아래, 532 위, 567 아래) 사이를 린이 지그재그로 오른쪽에서 왼쪽으로 흐르며 식는다.
- 새들(505, 565), 보닛, 튜브시트가 있고, 셸 노즐은 588(아래, 린 입구)과 468(위, 린 출구)이다.

**케틀 리보일러** (`REB` x 810–950, y 695–757, 넘침판 915, 채널 966)
- 스팀 채널에는 칸막이(y 726)가 있다. U자 튜브는 34.8 s부터 빨갛게 된다.
- 넘침판 왼쪽은 끓는 풀(물결 2.2, 기포 16개), 오른쪽은 넘친 린 용액 칸(출구 (935, 754))이다.

**액면** (`Liquid`, 용기 안쪽 모양 clipPath + 물결)
- 흡수탑 바닥 704 리치, 재생탑 바닥 672 린, 리보일러 713/738, 드럼 247 → 232(36.9–38.5 s).

**회전 기계**
- 펌프 임펠러는 540°/s로 돈다(29.0, 29.6, 37.2 s부터).
- 압축기는 900°/s로 돈다(56.8, 57.6, 58.4 s부터). 단마다 압력계 바늘이 풀 스케일의 0.3 / 0.6 / 0.9까지 오른다.

**배관** (`PIPES` 27개)
- 이름 붙은 배관 23개(flueIn, treated, leanA/B, richA/B, rebFeed, steam, rebVap, overhead, reflux, co2Comp, s1–s4, exit 등)와 인터쿨러 냉각수 배관 4개다.
- 각 배관에는 흐름 시작 시각(`t0`), 속도, 점 간격이 있다.
- 점의 종류:
  - 배가스: 분자 혼합
  - 처리 가스: CO₂ 대부분이 N₂로 바뀜
  - 오버헤드: H₂O 35%
  - 그 외: 스팀, CO₂, 린·리치·냉각수 점
- 설비에 닿는 끝에는 배관이 다 그려진 뒤 플랜지가 붙는다.
- 용액 순환 장(46.2–51 s)에서는 순환 경로 전체가 노란 혜성 대시로 빛난다.

**카메라** (`CAM` 21키)
- 전체(700, 430, ×0.72)에서 시작한다.
- 흡수탑(×1.2) → 렌즈 옆 → 흡수탑 위(×1.4) → 열교환기(×1.5) → 재생탑(×1.2) → 재생 렌즈 → 전체 순환(×0.95) → 응축기·드럼(×1.4) → 압축기(×1.25) 순으로 옮긴다.
- 63.2 s에 전체로 돌아온다.
