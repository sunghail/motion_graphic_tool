- 사용자는 "2bed PSA에 관한 거 너가 자세하게 구성해서"라고 요청했다. 그래서 장면 구성과 문구는 직접 짰다.

**시간 함수**

| 함수 | 뜻 |
|---|---|
| `cycleClock(t)` | 7 s 전에는 −1. 7–37 s는 `t−7`. 그 뒤는 `30 + (t−37)·3`(3배속) |
| `cycleState(t)` | 사이클 안 시각 `ct`, 단계 번호 `k`, 단계 안 시각 `tau`, 진행률 `u` |
| `pressureAt(bed, ct)` | 정규화 압력 0–1. PR 0.5→1, AD 1, EQD 1→0.5, BD 0.5→0, PU 0, EQR 0→0.5. 단계의 처음 80% 동안 변하고 이후 유지 |
| `frontAt(bed, ct)` | 불순물 전선 높이(0 = 흡착제 바닥, 1 = 꼭대기). PR 0.1→0.2, AD 0.2→0.7, EQD 0.7→0.78, BD 0.78→0.5, PU 0.5→0.1 |
| `valveAt(v, t)` | 앞 단계 개도에서 0.3 s 동안 새 개도로 변함 |
| `flowAlpha` | 흐름 표시가 단계 시작 0.3 s에 나타나고 끝 0.2 s에 사라짐 |
| `bedDots(bed, t)` | 탑 안 입자. 모드별 규칙(흡착: 위로 오르다 불순물 35%가 전선 아래에서 잡힘 / 탈압·퍼지: 아래로, 불순물 75%·90% / 퍼지는 위에서 H₂가 들어옴 / 균압: 위로 나가거나 위에서 들어옴) |
| `pipeDots(t)` | 배관 흐름 점 (2D만). 원료는 불순물 35%, 탈착 70%, H₂ 0% |

## 2D 버전 (`plant/Psa2D.tsx`, `scenes/Story2D.tsx`)

- 파란 격자 도면 배경. 줌 0.9, 초점 (470, 440).
- 도면 점선(0.1–0.6 s 등장, 4.4–5.2 s 퇴장).

- 배관은 `pathLength` 그리기(2.3–3.6 s)로 나오고, 흐름 색 덧칠과 흐름 점이 얹힌다.
- 밸브는 나비넥타이 모양 + 스템 + 구동기 상자다. 개도에 따라 색이 바뀐다.
- 탑은 딱 끊기는 금속 그라데이션으로 그리고, 단면이 열리면 속이 보인다(5.3–6.1 s).
  - 모래색 구슬 격자, 빨간 적재 띠(바닥부터 전선까지), 지지 스크린, 입자가 보인다.
- 탑 옆에는 압력계(바늘 = 압력)와 모드 배지를 둔다.

## 3D 버전 (`plant/Psa3D.tsx`, `plant/cam3d.ts`, `scenes/Story3D.tsx`)

**화면**
- 왼쪽 1080×1080에 `<ThreeCanvas shadows="soft">`를 두고 오른쪽은 패널이다.
- 한글 라벨은 HTML로 얹는다(`project()`). 탑 이름, 모드 배지, 밸브 이름, 헤더 이름, "착!"이 여기에 해당한다.

**카메라 키** `[t, 방위각°, 고도각°, 거리, 목표 x, 목표 y]`
- `[0, −40, 20, 25, 0.5, 3.5]` → `[6.5, −22, 12, 20.8, 0.5, 3.9]` → `[37, 14, 10, 20.2, 0.5, 3.9]` → `[57, 28, 14, 21.2, 0.5, 3.9]`, FOV 28.
- 움직임: 왼쪽 위에서 정면으로 돌아 들어온다 → 사이클 동안 천천히 흐른다 → 연속 운전 때 오른쪽으로 돈다.

**용기** (R 0.58, 경판 높이 0.32, 벽 두께 0.032)
- 옆모습 곡선(점 22개)을 `LatheGeometry` 반쪽 둘로 돌렸다. 앞 반쪽은 단면이 열리며 투명해진다.
- 잘린 벽면은 `ShapeGeometry`, 안쪽 벽은 BackSide 재질이다.
- 디테일:
  - 구조: 이음 용접선, 상하 노즐·플랜지, 맨홀, 러그 2개
  - 다리: H형 다리 4개, 베이스판, 앵커볼트 4개씩
  - 플랫폼: 격자 발판, 이중 난간, 브래킷, 케이지 사다리(가로대 0.3 간격, 둘레 고리 0.62 간격)
  - 계기: 압력계(바늘 = 압력), 압력 전송기
- 흡착제 구슬은 `instancedMesh` 하나에 탑당 약 2697개다(뒤쪽 반).
- 적재 구간은 빨간 반원기둥과 단면이다. 그 위에 옅은 물질전달 구간 판을 얹었다.

**배관·밸브**
- 배관은 방향을 맞춘 원통(`Rod`)이다. 조립 때 시작점에서 자라 나온다.
- T 연결부 공, 식별 색띠(원료 회색, H₂ 파랑, 탈착 갈색, 균압 청록), 볼트 8개짜리 플랜지.
- 지지 구조: 아연도금 파이프랙 2곳(x 470, 900), 원료 헤더 받침(x 80, 420), 탈착 헤더 콘크리트 침목(x 440, 700, 860).
- 밸브는 플랜지 볼밸브다. 파란 랙앤피니언 액추에이터, 솔레노이드, 노란 개도 표시기가 붙어 있고, 표시기는 개도 × 90° 회전한다.
- 흐름은 원뿔 화살표로 보여 준다. 경로 접선 방향으로 150 u/s로 움직인다.

**현장·조명**
- 절차 텍스처:
  - 자갈: 512², 점 9000개, 120×120 반복
  - 콘크리트: 점 5000개 + 256 px 간격 이음선
  - 하늘: `#a9c8e6` → `#e6ecf1` 그라데이션
- 자갈 바닥은 600×600이다. 그 위에 콘크리트 슬래브(11.6×5.2)와 탑 기초를 놓았다.
- 반사 환경은 `RoomEnvironment`를 PMREM으로 구워 쓴다(세기 0.7). 안개는 `Fog('#e6ecf1', 26, 95)`다.
- 조명:
  - 환경광 0.25, 반구광 0.6
  - 주광: (7, 14, 10), 2.3, 따뜻한 색, 그림자 맵 4096², 반경 4
  - 보조광: (−9, 6, 6), 0.5

**조립(3D)**
- 탑은 7.5 높이에서 가속하며 떨어진 뒤 튀어 오른다. 착지할 때 카메라가 흔들리고(`shake3`), 라벨도 같이 흔들린다.
- 받침은 배관보다 0.4 s 먼저 자란다. 밸브와 압력계는 `eob`로 톡 튀어나온다.
- 입자는 단면이 다 열린 6.1 s부터 나온다.

**"조금 더 리얼리티하게"에서 한 일**
- 추가한 것: 용접선, 맨홀·러그, 플랫폼·난간·케이지 사다리, H형 다리·앵커볼트, 계기, 플랜지 볼트, 색띠, 파이프랙·받침·침목, 액추에이터 밸브, 자갈·콘크리트 텍스처, 하늘·안개.
- 배관 재질을 불투명하게 바꿨다.
- 바닥을 넓히고 안개 색을 맞춰 지평선 경계를 없앴다.

## 가정과 한계

- 압력은 0–1로 정규화했다. 단계 시간(4·7·4·4·7·4 s), 전선 높이, 입자 비율은 보기 좋게 정한 값이다.
- 가압은 원료 가스로, 퍼지는 흡착 중인 탑의 제품 H₂ 일부로 V7을 반만 열어 한다고 가정했다.
- 장 길이는 `ChapterSeries`에 숫자로 따로 적혀 있다. `CHAPTERS`를 바꾸면 손으로 맞춰야 한다.
- 압력계 바늘 각도 부호는 2D(−220 + 260p)와 3D(220 − 260p)에서 반대다. y축 방향이 달라서다.
- `sim.ts`의 `settle`은 쓰이지 않는다.
