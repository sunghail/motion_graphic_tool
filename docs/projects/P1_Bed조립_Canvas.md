## 무엇을 보여 주나

PSA 흡착탑 한 기가 만들어지고 채워지는 과정이다.
설계 도면 → 부품 착착 조립 → 수압시험 → 단면 보기 → 톤백·호퍼로 5개 층 충전 → 배관 → 가스가 아래에서 위로 흐르며 성분별로 층에 잡힘.

층 구성은 H₂ PSA 3층 충전(알루미나 / 활성탄 / 제올라이트 5A, 위아래 세라믹 볼)을 예로 든 **설명용 그림**이다. 모델의 층 높이·입경·조성과는 연결되어 있지 않다.

**형상** (index.html:96-104)
- `W=1100, H=860, cx=400, R=120, TILT=0.22`: 타원 세로 = 반지름 × 0.22라서 수평 원처럼 보인다.

## 기법 (자세한 설명은 [03_제작원칙과_기법](../03_제작원칙과_기법.md))

- **평면 금속** `metalFill`(136-144): 몸통색, 오른쪽 그림자 띠, 왼쪽 밝은 줄, 잉크 외곽선.
- **착 조립** `snapT`(170-179)와 `withT`(180-183): 기준점 중심으로 변환한다.
- **구슬 궤적**: IIFE `buildBeads`(408-456)와 `vesselPos`(457-462)가 만든다.
  - 자리는 육각 배치다: dx = 2r·1.03, dy = 2r·0.87, 약간씩 흔들림.
  - 착지 순서는 `0.78·줄 비율 + 0.22·중심 거리`다. 그래서 아래 줄·가운데부터 찬다.
  - 더미 높이는 `min(0.28·줄 수·dy, 48)`이다.
  - 구르는 시간은 `0.1 + 0.32·|x−cx|/RI`다.
- **호퍼 용량** `cap = min(floor(C·0.85), ceil(N·0.5))`.
  - 처음 `cap`개는 더미 위로 쏟아진다.
  - 그다음부터는 하나가 빠지는 순간 새 구슬이 떨어진다(`te = S[i−cap]`).
  - 톤백에서 떨어지는 시각은 `tb = te − √(2(tgy−BAG_OUT)/G)`다.
- **톤백** `drawBag`(534-570): 크레인 고리와 파란 멜빵이 있다. 남은 양에 따라 `hb = 74·(0.35+0.65·rem)`로 줄어든다.
- **구슬 스프라이트** `makeSprite`(159-167): 5배 해상도로 한 번 그려 반복해 찍는다.
- **카메라** `CAM`(747-754): (550, 430, 1) → 12.5–38.9 s 동안 (550, 330, 0.88) → 39.8 s에 복귀.
- **HiDPI**: ResizeObserver와 devicePixelRatio를 쓴다. 재생은 `requestAnimationFrame`, dt 상한 0.05 s.
