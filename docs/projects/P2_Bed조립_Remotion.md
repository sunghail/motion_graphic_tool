## 흡착 표현 (사용자 요청 반영의 핵심)

sim.ts:258-262 설계 주석을 요약하면 다음과 같다.
- 새 흡착제는 각 성분을 **그 층의 아래(입구)**에서 잡는다. 그래서 적재 영역은 앞 영역이 끝난 곳에서 위로 자란다.
- H₂O는 알루미나에 머문다.
- CO₂·CH₄·CO·N₂는 거의 모두 활성탄이 잡는다. 강하게 흡착되는 것이 먼저 잡히므로 CO₂가 아래, N₂가 위다.
- 제올라이트 5A는 최종 방어층이다. 넘어온 N₂ 조금만 그 바닥에 붙는다.

| 성분 | 색 | 비율 | 잡히는 곳 | 범례 |
|---|---|---|---|---|
| H₂ | `#0891b2` | .4 | 통과 | 통과 → 제품 |
| H₂O | `#2563eb` | .12 | 알루미나 (기준 626) | 활성 알루미나 |
| CO₂ | `#dc2626` | .17 | 활성탄 (기준 556) | 활성탄 |
| CH₄ | `#16a34a` | .11 | 활성탄, CO₂ 위 | 활성탄 |
| CO | `#9333ea` | .1 | 활성탄, CO₂·CH₄ 위 | 활성탄 |
| N₂ | `#ea580c` | .1 | 활성탄, CO₂·CH₄·CO 위 / 30%는 5A 바닥(`N2z`, 기준 386) | 활성탄 · 일부 5A |

- 영역 성장: 잡힌 분자 하나당 `ZONE_DH = 2` px 자란다. 분자는 그 순간 영역 앞쪽에서 3–15 px 아래에 멈춘다(짧은 물질전달 구간).
- 분자는 41.8 s부터 48.6 s까지 초당 15개, 모두 103개 나온다. 성분별로 H₂ 39, H₂O 14, CO₂ 20, CH₄ 11, CO 8, N₂ 11개이고, 그중 N₂ 5개가 5A로 간다.
- 최종 영역:
  - H₂O: 626 → 598
  - 활성탄: CO₂ 556 → 516, CH₄ → 494, CO → 478, N₂ → 466
  - 5A의 N₂: 386 → 376

## 실행

```bash
npm install
npm run dev       # Studio: PsaBed, PsaBed-Scenes 폴더에서 장면별 미리보기
npm run render    # out/psa-bed-60fps.mp4 (--concurrency=4)
npm run still     # 1800프레임(t=27 s, 활성탄 장) → out/still.png
```
