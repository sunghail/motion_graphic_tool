## Remotion 프로젝트 공통 설정

- `remotion.config.ts`: `Config.setVideoImageFormat('jpeg')`, `Config.setOverwriteOutput(true)`
  - 중간 프레임이 JPEG라서 결과 영상의 픽셀 형식이 `yuvj420p`(full range)로 나온다.
- `tsconfig.json`: ES2020 target, ESNext 모듈, bundler resolution, `react-jsx`, strict, noEmit, lib ES2022+DOM.
- `.gitignore`: `out/` (렌더 결과는 git에 올리지 않음).
- `package.json` 스크립트:
  - `dev` = `remotion studio`
  - `render` = `remotion render <Comp> out/<파일>.mp4 --concurrency=4`
  - `still` = `remotion still <Comp> out/still.png --frame=1800`
  - P4만 `render3d` = `remotion render Psa2Bed3D out/psa-2bed-3d-60fps.mp4 --concurrency=4 --gl=angle`

## Remotion Agent Skills

Remotion 코드 작성 규칙을 담은 에이전트 스킬 모음이다(출처 GitHub `remotion-dev/skills`).

- **설치 원칙: 프로젝트 폴더의 `.claude/skills/`에만 설치한다. 전역(`~/.claude/skills`) 설치는 하지 않는다.** (사용자 요청)
- 설치 명령(프로젝트 폴더 안에서):
  ```bash
  npx skills add remotion-dev/skills -a claude-code -s '*' -y --copy
  ```
- 제거: 그 폴더에서 `npx skills remove --all`.
- `skills-lock.json`에 출처(`remotion-dev/skills`, github), 경로(`skills/<name>/SKILL.md`), 해시가 기록된다.
- 설치된 12개:
  - remotion-best-practices (라우터, 4.0.527)
  - remotion-captions, remotion-create, remotion-docs, remotion-interactivity
  - remotion-maps, remotion-markup, remotion-multimedia, remotion-render
  - remotion-saas, remotion-studio, remotion-upgrade
- 중복 사본: `remotion-best-practices` 안에 나머지 11개가 한 벌 더 있고, `remotion-markup` 안에 `remotion-maps`가 있다. 파일은 모두 271개다.
- 설치 위치: P2에 먼저 설치하고, P3·P4에는 P2 폴더에서 복사했다. **이 저장소에는 스킬 사본을 넣지 않았다.** `skills-lock.json`만 있으니 위 명령으로 설치한다.
- 이 작업에서 특히 따른 규칙:
  - 모든 움직임은 `useCurrentFrame()`에서 계산한다.
  - 3D는 `<ThreeCanvas width height>`로 감싼다.
  - **`@react-three/fiber`의 `useFrame()`은 금지**다(`remotion-markup/3d.md`).
  - 장면 연결은 `TransitionSeries`, 순서 배치는 `Series`, 등장 전 준비는 `premountFor`를 쓴다.
  - Studio 편집용으로 `Interactive.Div`를 쓰고, `interpolate(..., {easing: Easing.spring(...), output: 'perceptual-scale'})`를 쓴다.

## 이 PC에서의 주의점

| 증상 | 원인·해결 |
|---|---|
| `remotion render`가 "Page crashed"로 실패 | 32코어 PC에서 기본 동시 작업 수가 너무 많다. **`--concurrency=4`**를 npm 스크립트에 넣었다 |
| 3D 렌더가 검거나 실패 | WebGL용 **`--gl=angle`**을 준다 |
| 한글 글꼴 요청이 너무 많다는 경고 | 한글은 유니코드 구간 약 100조각으로 나뉜다. 굵기를 3개(500/700/900)로 줄이고 `ignoreTooManyRequestsWarning: true`를 준다. Black Han Sans는 뺐다 |
| 글꼴·효과음이 안 나옴 | 렌더 중에 Google Fonts와 remotion.media에서 받아 온다. **인터넷이 필요하다** |
| `python -c "..."` 여러 줄이 실패 | 셸 래퍼 문제("goto :error"). 스크래치 `.py` 파일을 만들어 실행하거나 한 줄로 쓴다 |
| heredoc 안의 `'\\'`가 `'\'`로 바뀜 | 경로는 `os.path.join`이나 `/`를 쓴다 |
| Blender 스크립트에서 `nodes["Principled BSDF"]`가 KeyError | Blender UI가 한국어라 노드 이름도 한국어다. **노드는 이름이 아니라 `n.type`으로 찾는다** |
| Blender 5 컴포지터 API 변경 | `scene.node_tree` 대신 `scene.compositing_node_group`과 `NodeGroupOutput`을 쓴다. P5 스크립트는 두 방식을 모두 처리한다 |
| Blender `use_nodes` 경고 | Blender 6.0에서 제거 예정이라는 DeprecationWarning이다. 지금은 무시해도 된다 |
| 3D 미리보기 캡처가 예전 화면 | 미리보기 창이 숨겨져 있으면 WebGL이 다시 그리지 않는다. 확인은 `npx remotion still`로 한다 |
| 결과 파일 전송 한도 | 30 MB가 넘는 MP4는 휴대폰·웹으로 보낼 수 없고 데스크톱 앱에서만 볼 수 있다. P3(58.7 MiB)와 P4-3D(49.3 MiB)가 이에 해당한다 |

## 라이선스 메모

- Remotion은 개인과 소규모 팀은 무료이고, 일정 규모 이상의 회사는 유료 라이선스가 필요하다(remotion.dev/license).
- Manim, matplotlib, Blender는 무료 공개 소프트웨어다.
- 효과음(`@remotion/sfx`)과 글꼴(Noto Sans KR, SIL OFL)은 각 제공처 조건을 따른다.
