# 05 새 모션그래픽 시작하기

새 작업은 저장소 `projects/` 안에 번호를 붙인 폴더로 만든다. 예: `projects/P6_4bed_psa_remotion/`.
끝나면 [01_작업목록과_이력.md](01_작업목록과_이력.md)에 한 줄을 추가하고, `docs/projects/`에 상세 기록을 남긴다.

## 1. 도구 고르기

| 만들 것 | 추천 도구 | 기존 예 |
|---|---|---|
| 공정 소개·설명 영상 (장 구성, 큰 글자 패널, 효과음) | Remotion + SVG | P2, P3, P4-2D |
| 설비를 실제처럼 보여 주는 영상 | Remotion + Three.js (설명 패널 유지) 또는 Blender (표지용) | P4-3D, P5-04 |
| 반응식·원리·개념 | Manim | P5-02 |
| 시뮬레이터 계산 결과(압력·조성·온도 프로파일) | matplotlib 애니메이션 | P5-03 |
| 웹 화면 안에서 바로 재생·조작 | HTML Canvas / SVG + JS | P1 |

## 2. 시작 전 확인할 것 (사용자에게 질문)

- 범위: 공정의 어디부터 어디까지인가
- 대상: 어떤 원료·흡착제·흡수제인가, 몇 탑인가
- 형식: 기존 영상(P2~P4) 형식을 따르나, 조립 장면을 넣나, 2D·3D 중 무엇인가
- 길이와 fps: 기본은 60fps, 1920×1080
- **화면 문구 전체 표를 먼저 보여 주고 확인받는다.**

## 3. Remotion 프로젝트 만들기

가장 빠른 방법은 기존 프로젝트를 복사해 고치는 것이다.

```bash
# 예: P4를 복사해서 시작 (node_modules, out 제외)
SRC="projects/P4_2bed_psa_remotion"
DST="projects/P6_new_work"
mkdir -p "$DST"
cp -r "$SRC"/{src,package.json,package-lock.json,remotion.config.ts,tsconfig.json,.gitignore,skills-lock.json} "$DST"/
cd "$DST" && npm install
```

- Remotion Agent Skills는 저장소에 없다. 필요하면 새 폴더에서 `npx skills add remotion-dev/skills -a claude-code -s '*' -y --copy`를 실행한다. **전역 설치는 하지 않는다.**
- 3D가 필요 없으면 `three`, `@react-three/fiber`, `@remotion/three`, `@types/three`를 빼도 된다.
- `package.json`의 `name`, 컴포지션 id, 결과 파일 이름을 바꾼다. `render` 스크립트에는 `--concurrency=4`를 유지한다.

### 파일 뼈대

```
src/
  index.ts          registerRoot
  Root.tsx          <Composition id="..." durationInFrames fps={60} width={1920} height={1080}/> + 장면 Folder
  Video.tsx         TransitionSeries: Intro(210) → fade(30) → Story → fade(36) → Outro(330)
  fonts.ts          Noto Sans KR 500/700/900, ignoreTooManyRequestsWarning
  sim.ts            좌표·시간표·CHAPTERS·상태 함수·입자 함수 (그림 없음, 모두 t의 순수 함수)
  plant/            설비 그림 (SVG 또는 Three.js)
  scenes/
    Story.tsx       설비 + 패널 + <Series> 장 카드 + 보조 카드 + 진행 막대 + 효과음
    ChapterCard.tsx
    Intro.tsx, Outro.tsx
```

### sim.ts에 먼저 정할 것

1. 세계 좌표계: 바닥 y, 설비 중심·크기. 오른쪽 패널을 피해 왼쪽 1080 px 안에 들어오게 한다.
2. 조립 시간표: 부품별 [날아옴, 착지] 시각, 충격 목록.
3. 장 목록 `CHAPTERS`: `{t, g, title, desc}`.
4. 공정 상태 함수: 단계, 개도, 압력, 전선, 흐름 시작 시각.
5. 입자 함수: 인덱스 n으로 태어난 시각을 정하고, 나이로 위치를 계산한다. `h1(n·상수)`로 무작위를 만든다.
6. 카메라 키 `[t, fx, fy, zoom]`.

## 4. 만들면서 지킬 것

- `Math.random`, `useFrame`, 누적 상태는 쓰지 않는다.
- 선은 입자·분자보다 먼저 그린다(가림 방지).
- 액면·입자는 용기 모양 `clipPath` 안에 넣는다.
- 배관 끝 좌표는 설비 상수에서 계산해 노즐에 정확히 닿게 한다.
- 핵심 현상은 조금 느리고 크게, 비율을 과장해서라도 보이게 한다. 과장한 값은 README에 "설명용 값"이라고 적는다.
- `npx tsc --noEmit`를 자주 돌리고, `npx remotion still ... --scale=0.5`로 장면별 한 장씩 본다.
