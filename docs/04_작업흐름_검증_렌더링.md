# 04 작업 흐름, 검증, 렌더링

## 1. 작업 순서

1. **먼저 질문한다.** 범위, 대상 공정, 형식, 넣을 장면처럼 모호한 점을 선택지로 묻는다.
   - 예: P3에서는 범위(압축까지), 배가스원(LNG 복합발전), 흡수제(MEA + 분자 장면), 형식(PSA 형식 + 조립)을 물었다.
2. **화면 문구를 표로 확인받는다.** 장 제목, 설명, 라벨을 한 번에 보여 주고 고칠 곳을 받는다.
3. **`sim.ts`를 먼저 쓴다.** 좌표, 시간표, 장 목록, 입자·흐름 함수를 적는다.
4. **그림과 장면을 쓴다.** 설비(`plant/`) → 본편(`scenes/*Story.tsx`) → Intro/Outro → `Root.tsx` 등록.
5. **타입 검사**: `npx tsc --noEmit`
6. **장면별로 한 장씩 뽑아 눈으로 본다.** 문제가 있으면 고치고 다시 뽑는다.
7. **전체 렌더링** 후 프레임 수와 fps를 확인한다.
8. 결과를 보내고 피드백을 받는다. 고칠 부분만 고쳐 다시 렌더링한다.

## 2. 명령 모음

### Remotion (P2~P4, 각 프로젝트 폴더에서)

```bash
npm install
npm run dev                                   # Remotion Studio (미리보기·타임라인)
npx tsc --noEmit                              # 타입 검사
npx remotion still PsaBed out/check.png --frame=1800 --scale=0.5   # 한 장 확인 (절반 크기)
npm run render                                # 2D / 기본 컴포지션 → out/
npm run render3d                              # P4 3D (--gl=angle)
```

| 프로젝트 | 컴포지션 | 결과 |
|---|---|---|
| P2 | `PsaBed` (장면 폴더 `PsaBed-Scenes`: Intro, BedStory, Outro) | `out/psa-bed-60fps.mp4` |
| P3 | `CcsCapture` (`Ccs-Scenes`: Intro, CcsStory, Outro) | `out/ccs-capture-60fps.mp4` |
| P4 | `Psa2Bed`, `Psa2Bed3D` (`Psa2Bed-Scenes`: Story2D, Story3D) | `out/psa-2bed-2d-60fps.mp4`, `out/psa-2bed-3d-60fps.mp4` |

- 3D 확인 사진: `npx remotion still Psa2Bed3D out/c.png --frame=N --gl=angle`
- 확인용 프레임은 장이 바뀐 직후, 핵심 현상 중간, 끝부분에서 고른다.
  - 장 시작 프레임 = (Intro 210 − 페이드 30) + 장 시각 × 60

### 결과 확인 (ffmpeg)

```bash
FF=$(python -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
"$FF" -i out/psa-bed-60fps.mp4                    # Duration, fps, 해상도 (stderr로 출력)
"$FF" -i out/x.mp4 -map 0:v -f null - 2>&1 | tail -3   # 전체 디코드로 프레임 수 확인
"$FF" -y -ss 12 -i out/x.mp4 -frames:v 1 -vf scale=960:-1 check.png   # 12초 화면 한 장
"$FF" -y -i x.mp4 -vf "select='eq(n\,10)+eq(n\,260)',scale=640:-1,tile=2x1" -frames:v 1 pair.png  # 두 프레임 나란히
"$FF" -y -ss 10 -to 24 -i src.mp4 -c:v libx264 -crf 22 clip.mp4   # 구간 잘라내기 (P5-01)
```

## 3. 렌더링 시간·크기 (이 PC 실측)

| 결과 | 프레임 | 시간 | 크기 |
|---|---|---|---|
| P2 2D (concurrency 4) | 3474 | 기록 없음 | 16.0 MiB |
| P3 2D | 4014 | 기록 없음 | 58.7 MiB |
| P4 2D | 3894 | 기록 없음 | 23.3 MiB |

- Blender만 로그(`render.log`)로 소요 시간을 확인했다. 다음 작업부터는 렌더 시간을 적어 두면 계획 세우기에 좋다.

## 4. 겪은 오류와 해결

| # | 프로젝트 | 증상 | 해결 |
|---|---|---|---|
| 1 | P2~ | 렌더 중 "Page crashed" | `--concurrency=4`를 npm 스크립트에 넣었다 |
| 2 | P2 | 한글 글꼴 요청 과다 경고 | Black Han Sans를 빼고 Noto Sans KR 900으로 대체, 굵기 3개로 제한 |
| 3 | P2 | TS 오류: `layout="none"`인 `Sequence`에 `premountFor`를 줄 수 없음 | 장면 `Series.Sequence`에서 `layout`을 뺐다. 효과음 `Sequence`만 `layout="none"` |
| 4 | P2 | 흡착이 층 중간에서 잡힘 | 층의 아래부터 자라는 `ZONES` 방식으로 바꿨다 |
| 5 | P3 | 오른쪽 패널이 설비 그림과 겹침 | x 1080부터 불투명 패널 배경을 깔았다 |
| 6 | P3 | 분자 렌즈가 탑을 가림 | 렌즈 위치를 (720, 520)으로 옮기고 카메라 초점도 옮겼다 |
| 7 | P3 | 액면이 사각형이고 용기 모양과 안 맞음 | 용기별 `clipPath`와 물결 표면 `Liquid` 컴포넌트를 만들었다 |
| 8 | P3 | 열교환기 배관이 노즐과 어긋남 | 쉘앤튜브로 새로 그렸다. 노즐 좌표를 `HX`, `REB` 상수에서 배관 경로로 직접 이었다 |
| 9 | P3 | 결합선이 원자(N)를 가림 | 결합선을 원자보다 먼저 그렸다 |
| 10 | P3 | 흡수탑에서 CO₂가 잡히는 게 안 보임 | CO₂ 점 비율 32%, 잡힘 고리 효과, 액적에 올라타 내려감, 속도를 늦춤 |
| 11 | P3 | 배가스 냉각 장 삭제로 시각이 전부 밀림 | 이야기 시계 건너뛰기(`SKIP_AT=7`, `SKIP=5`) |
| 12 | P4 | 3D 확인 캡처가 예전 화면 | 미리보기 창이 숨겨져 있으면 다시 그려지지 않는다. `remotion still`로 확인한다 |
| 13 | P4 | 3D 배관이 너무 투명함 | 배관 재질을 불투명하게 |
| 14 | P4 | 3D 지평선이 딱딱한 선으로 보임 | 자갈 바닥을 600×600으로 넓히고 안개 색을 하늘 아래 색(`#e6ecf1`)과 맞췄다 |
| 15 | P4 | (예방) 3D 깜빡임 | `useFrame`을 쓰지 않는다. 모든 것을 `t`로 계산한다 |
| 16 | P5 | matplotlib 린 로딩 곡선이 5 s에서 튐 | 부드러운 봉우리 `0.05·sin(π·ramp(s,5,8.5))`로 바꿨다 |
| 17 | P5 | matplotlib 색이 둥근 탑 밖으로 삐져나옴 | `img.set_clip_path(box)` |
| 18 | P5 | Manim `VGroup`에 `Group`을 넣어 TypeError | 전체 페이드아웃에 `Group(*self.mobjects)`를 썼다 |
| 19 | P5 | Manim 글자 겹침(탑 이름, 반응식, "압축") | 탑 이름을 탑 안 위쪽으로, "압축"을 상자 위로, 탑 높이를 줄였다 |
| 20 | P5 | Blender `KeyError: "Background"`, `"Principled BSDF"` | UI가 한국어라 노드 이름도 한국어였다. `n.type`으로 찾는다 |
| 21 | P5 | Blender 첫 결과가 너무 밝아 발광 입자가 묻힘 | 배경·바닥을 어둡게, 발광 세기를 올리고 bloom(Glare)을 넣었다. 카메라를 뒤로 빼 압축기까지 화면에 담았다 |
| 22 | 셸 | 여러 줄 `python -c` 실패, heredoc 역슬래시 깨짐 | 스크래치 `.py` 파일을 쓰고, 경로는 `/`나 `os.path.join` |

## 5. 확인 목록 (보내기 전)

- [ ] 프레임 수·fps가 컴포지션 설정과 같은가 (ffmpeg)
- [ ] 장이 바뀐 직후와 핵심 현상 중간을 한 장씩 눈으로 봤는가
- [ ] 글자가 설비·분자·다른 글자와 겹치지 않는가
- [ ] 선이 분자·입자를 가리지 않는가 (그리는 순서)
- [ ] 액면·입자가 용기 밖으로 나가지 않는가 (clipPath)
- [ ] 배관 끝이 노즐에 정확히 닿는가
- [ ] 사용자가 확인한 문구와 화면 문구가 같은가
- [ ] 30 MB가 넘으면 "데스크톱 앱에서만 볼 수 있다"고 알렸는가
