# 03 제작 원칙과 기법

코드 위치는 저장소 `projects/` 아래 각 프로젝트 기준이다(P1 = `P1_bed_canvas/index.html`, P2~P4 = `P*/src/...`). 줄 번호는 2026-09-27 기준이다.

## 1. 핵심 원칙

### 1-1. 모든 화면은 시각 t의 순수 함수

- `t = frame / fps`(초)만으로 위치·색·압력·입자·액면을 계산한다.
- 이전 프레임의 상태를 쌓아 두지 않는다. 실시간 물리 계산도 하지 않는다.
- 그래서 어느 프레임을 먼저 그려도 결과가 같다. 이 성질 덕분에 되는 것들:
  - Remotion이 프레임을 여러 개로 나눠 **병렬 렌더링**할 수 있다.
  - Studio에서 **아무 시점으로 건너뛰어도** 정확한 화면이 나온다.
  - P1의 `?t=33&pause` 같은 시점 지정 URL이 가능하다.
- 입자도 같은 방식이다. 입자 n은 "n/R초에 태어남"으로 정의하고 나이 `a = τ − n/R`로 위치를 계산한다. 입자 목록을 저장하지 않는다.
- 3D(P4)도 `useFrame` 없이 `t`로 모든 행렬을 계산해 `useLayoutEffect`에서 넣는다.
- Blender(P5)도 파이썬 함수 `fn(t)`로 위치를 계산해 2프레임마다 키프레임으로 박는다.

### 1-2. 무작위도 결정적으로

`Math.random`이나 `random` 대신 해시와 시드 난수를 쓴다.

```ts
h1(i) = frac(sin(i*127.1 + 311.7) * 43758.5453)   // 0..1, 같은 i면 늘 같은 값
mulberry(seed)                                      // 시드 난수 (P1: 7, P2: 층마다 7 + r·13)
np.random.default_rng(3)                            // matplotlib 예시
```

- 균일하게 퍼뜨릴 때는 황금비를 쓴다: `xi = frac(i·0.6180339887 + .31)`. P1·P2의 구슬 x 분산에 썼다.

### 1-4. 화면 구성

- 1920×1080 화면에서 왼쪽 1080 px에 설비, 오른쪽 840 px에 설명 패널을 둔다. 패널은 불투명 배경이고 왼쪽에 4 px 잉크 선을 긋는다.
- 패널 카드는 x 1120, 폭 720에 둔다.
  - 장 카드는 y 96: 알약 모양 "STEP 0N · 그룹"(30 px), 제목(96 px/900), 설명(50 px/500, `wordBreak: keep-all`).
  - 가운데는 보조 카드다: 층 쌓기 현황, 범례, 사이클 차트.
  - y 968에 진행 막대(장별 알약 + 그룹 이름)를 둔다.
- 카메라 초점을 왼쪽 영역 중심(540, 540)에 맞춘다. 패널이 화면 오른쪽을 가리기 때문이다.
- 영상 흐름: Intro(3.5 s) → 페이드 30 f → 본편 → 페이드 36 f → Outro(5.5 s).
- 본편 안의 장은 `<Series>`에 `premountFor={30}`으로 이어 붙인다.
- 스타일은 "평면 2D"다. 단색 면에 진한 외곽선(`INK #27313d`)을 두르고, 딱 끊기는 명암 띠를 넣는다. 강조색은 파랑 `#2563eb`, "착!" 글자는 주황 `#f59e0b`다.

### 분자 확대(P3)

- 설비 위 한 점에서 점선을 뽑아 원형 렌즈(중심 (720, 520), 반지름 300)로 확대한다.
- 렌즈는 `eob`로 튀어나오고 `eio`로 줄어든다.
- 원자 색·크기: O 빨강(r17), C 회색(r16), N 파랑(r17), H 흰색(r9). 이중결합은 선 두 줄로 그린다.
- **결합선을 먼저, 원자를 나중에 그린다.** SVG는 나중에 그린 것이 위에 온다. 선이 원자를 가리던 문제를 이렇게 고쳤다.
- 흡수 장면: CO₂가 MEA의 N에 붙으며 120°로 굽고, H⁺가 옆 MEA로 옮겨 가고, −/+ 전하가 표시된다. 반응식 알약: `2 MEA + CO₂ → MEA–COO⁻ + MEAH⁺`.
- 재생 장면: 열 물결 → 떨림 → 결합이 끊기고 CO₂가 위로 나간다. "열" 배지와 반응식 알약: `MEA–COO⁻ + MEAH⁺ → 2 MEA + CO₂`.

### 시간표 요령

- 조립, 흐름 시작, 장 시작 같은 시각을 모두 `sim.ts` 한곳에 둔다.
- 중간 장을 뺄 때는 모든 시각을 다시 짜지 않고 **이야기 시계를 건너뛰게** 한다(P3 `storyTime`, `videoTime`).
- 느린 한 바퀴 설명 뒤 빠른 반복: `cycleClock = 30 + (t−37)·3`(P4). 20초 동안 두 바퀴가 돈다.
- 장 길이(프레임)는 `Series` 안에 숫자로 직접 적는다. Studio에서 고칠 수 있게 하려는 것이다. 대신 `CHAPTERS` 시각과 **손으로 맞춰야** 한다.

## 3. 표현상의 약속

- 수치(농도·온도·압력)는 화면에 넣지 않는다(P3). P4의 압력도 0~1로 정규화한 값이다.
- 보이게 하려고 과장한 값이 있다. 모두 "설명용 값"이다.
  - P3 흡수탑 CO₂ 점 32%, 배가스 배관 22% (실제는 약 4%)
  - P1·P2 성분 비율
  - P4 단계 시간 4·7·4·4·7·4 s와 전선 높이
- PSA 층 역할은 사용자가 정했다.
  - 알루미나: H₂O
  - 활성탄: CO₂·CH₄·CO·N₂ 대부분, 강한 것부터 아래에서 쌓임
  - 제올라이트 5A: 최종 방어층, 넘어온 N₂ 조금이 바닥에 붙음
